# GeoExplorer - GeoJSON Leaflet Viewer

A premium React application to visualize any GeoJSON file using Leaflet.

## Features

- **Interactive Map**: Built with Leaflet and React-Leaflet.
- **Drag & Drop**: Easily upload GeoJSON files.
- **Auto-Fitting**: Map automatically zooms to the uploaded data bounds.
- **Feature Inspection**: Click on any map feature to see its properties.
- **Premium Design**: Dark mode aesthetic with Glassmorphism effects.

## Technologies

- React 18
- Vite
- Leaflet & React-Leaflet
- Lucide React (Icons)
- Google Fonts (Outfit)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser and upload a GeoJSON file!
